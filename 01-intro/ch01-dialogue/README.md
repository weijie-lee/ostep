# 第 1 章 对话

这一章只提出问题：很多程序同时存在，机器上的 CPU 却少得多。实验不写新程序，直接数这台机器上的进程和 CPU。

## 实验步骤

1. 在 shell 里执行：

```bash
uname -sr
nproc
ps -e --no-headers | wc -l
```

2. 把 CPU 个数和进程个数写下来，再进入第 2 章看一个进程实际占用 CPU、内存和磁盘时发生什么。

## 实验结果

本次采样：

```text
Linux 6.12.94+
nproc=4
ps 进程数=39
```

进程个数会随机器变化。这次是 4 个 CPU、39 个进程。

## 结果说明

进程数大于 CPU 数，所以不可能每个进程都一直占着一个核。操作系统要做的三件事由此分开：把 CPU 和内存虚拟化、让共享数据的执行变正确、把数据放到断电还在的设备上。第 2 章的三个程序分别碰这三件事。
