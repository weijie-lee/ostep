# 第 2 章 Introduction

三个程序各做一件事：空转占 CPU、分配并访问内存、把字节写进文件再读回来。

## 实验步骤

1. 在仓库根目录编译并运行：

```bash
make
./build/01-intro/ch02-introduction/cpu
./build/01-intro/ch02-introduction/mem
./build/01-intro/ch02-introduction/io
```

2. `cpu` 的累加结果应当每次相同。`mem` 的指针每次不同，求和应当相同。`io` 应当读回 `persistence`。

## 实验结果

```text
cpu: 循环 50000000 次，累加结果 1283106752
cpu: 这段时间进程一直处于运行态，操作系统用时间片让别的进程也有机会跑

mem: malloc 返回虚拟地址 0x55c294a502a0，共 16384 字节
mem: 抽样求和 = 6144（地址是否连续由硬件和页表保证，程序只看到线性空间）

io: 进程调用 write，在数据进入内核缓冲区之前它在系统调用里等待
io: read 返回 "persistence"（文件是持久抽象，进程退出后数据仍在这块临时文件里）
```

虚拟地址每次运行都会变。抽样求和固定是 `0+1024+2048+3072=6144`。

## 结果说明

- `cpu` 把 `0+1+...+49999999` 累加进 32 位无符号整数，结果回绕成 `1283106752`。这段时间进程处于运行态。
- `mem` 拿到 16384 字节的虚拟内存，程序按连续下标使用，不用自己算物理地址。
- `io` 通过系统调用把 12 个字节写入临时文件再读回。进程在 `read`/`write` 里会阻塞，CPU 可以去跑别的进程。
