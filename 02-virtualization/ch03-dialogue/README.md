# 第 3 章 对话

问题是：只有一个 CPU 时，两个进程能不能同时处于运行态。用第 4 章的状态机把一次调度记下来。

## 实验步骤

1. 在仓库根目录运行：

```bash
python3 02-virtualization/ch04-processes/states.py
```

2. 每一行只看 `A:` 和 `B:` 后面的状态，数同一行里有几个“运行”。

## 实验结果

```text
t=00 A:运行 B:就绪
t=01 A:阻塞 B:就绪
t=02 A:阻塞 B:运行
t=03 A:阻塞 B:运行
t=04 A:就绪 B:运行
t=05 A:就绪 B:结束
t=06 A:运行 B:结束
t=09 A:结束 B:结束
```

完整 10 行见第 4 章。任意一行里，“运行”最多出现一次。`t=01` 时 A 已经阻塞、B 还没被选上，这一拍没有运行态进程。

## 结果说明

单 CPU 的机制部分只保证“至多一个进程在跑”。谁被选上是策略，从第 7 章开始比较。A 阻塞的三拍里 B 得到了 CPU，这就是虚拟化要保住的现象。
