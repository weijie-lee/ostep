# 第 6 章 Direct Execution

用户程序的普通指令直接在 CPU 上跑。系统调用和时钟中断陷入内核。用户态执行关中断（`cli`）必须失败，硬件中断仍保持打开。

## 实验步骤

1. 运行：

```bash
python3 02-virtualization/ch06-direct-execution/lde.py
```

2. 程序里的指令序列是：3 条普通计算、1 次 `gettime` 系统调用、1 次用户态 `cli`、再 1 条计算。时钟每 3 条普通指令抢占一次。

## 实验结果

```text
用户指令执行 4 条，系统调用 1 次，时钟切换 1 次
用户态执行 cli 被拒绝 1 次，中断仍然开着：True
被抢占期间另一个进程前进了 1 个时间片
通过：普通指令直接执行，特权指令和时钟都陷入内核
```

## 结果说明

4 条 `compute` 都在用户态完成，所以直接执行没有额外解释开销。`gettime` 陷入一次再返回用户态。`cli` 在用户态被记成故障，`interrupts` 仍是 `True`。第 3 条计算之后时钟中断把另一个进程向前推了一个时间片，这就是内核夺回 CPU 的办法。
