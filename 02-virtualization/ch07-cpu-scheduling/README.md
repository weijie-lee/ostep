# 第 7 章 CPU Scheduling

比较 FIFO、SJF、STCF 和时间片为 1 的 RR。周转时间 = 完成时刻 − 到达时刻。响应时间 = 第一次运行 − 到达时刻。

## 实验步骤

1. 运行：

```bash
python3 02-virtualization/ch07-cpu-scheduling/scheduler.py
```

2. 三组输入都写在程序里，不用改参数：
   - 车队：A=100、B=10、C=10，同时在 t=0 到达
   - 抢占：A=100 在 t=0 到达，B=10 在 t=10 到达
   - 响应时间：A、B、C 都是 10，RR 时间片为 1

## 实验结果

```text
FIFO：长作业 A 排在前面，B 和 C 被堵住
  时间线: A[0-100] B[100-110] C[110-120]
  平均周转 110.0  平均响应 70.0

SJF：短作业先跑。需要预知运行时间，而且这里不抢占
  时间线: B[0-10] C[10-20] A[20-120]
  平均周转 50.0  平均响应 10.0

SJF 不抢占：B 在 t=10 到达，也得等 A 跑完
  A 周转 100，B 周转 100，平均周转 100.0

STCF：B 到达后立刻抢占 A
  时间线: A[0-10] B[10-20] A[20-110]
  A 周转 110，B 周转 10，平均周转 60.0，平均响应 0.0

RR 时间片 = 1
  A 周转 28 响应 0
  B 周转 29 响应 1
  C 周转 30 响应 2
  平均周转 29.0  平均响应 1.0
```

等长三作业若用 FIFO，平均响应时间是 `(0+10+20)/3 = 10`。

## 结果说明

同样三份作业，长作业先跑的平均周转时间是 110，短作业先跑是 50。SJF 不抢占时，t=10 到达的 B 要等 A 跑完，周转时间是 100；STCF 立刻抢占，B 的周转时间降到 10。RR 把平均响应时间从 10 压到 1，等长作业的平均周转时间变成 29，比 FIFO 的 20 更差。
