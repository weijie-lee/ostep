# 第 9 章 Lottery Scheduling

每次随机抽一张彩票，谁中谁跑一个时间片。票数占比就是长期应得到的 CPU 占比。步长调度用确定性的步进得到同一比例。

## 实验步骤

1. 运行：

```bash
python3 02-virtualization/ch09-lottery-scheduling/lottery.py
```

2. 彩票实验的随机种子固定为 1。A 持有 75 张，B 持有 25 张。短实验 20 个时间片，长实验 20000 个。步长实验里 A 的票是 100，B 的票是 50，共 300 个时间片。

## 实验结果

```text
彩票  A:B = 75:25
  只跑 20 个时间片：A 15  B 5（比例可以偏得很厉害）
  跑 20000 个时间片：A 得到 0.750，期望 0.750
步长调度 A 票 100、B 票 50，300 个时间片：A 200  B 100
通过：彩票数决定长期比例，步长调度用同样的比例但没有随机波动
```

## 结果说明

20 个时间片时 A 拿到 15/20=0.75，这次刚好贴近期望，换一种短序列就会偏。20000 次之后 A 的比例是 0.750，和 75/100 一致。步长调度里 A 的步长是 B 的一半，300 次里正好是 200 比 100，没有随机抖动。
