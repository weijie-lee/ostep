# 第 10 章 Multi-CPU Scheduling

三个作业各需要 12 个时间单位，缓存都在 CPU0 上。换一颗核要先付 5 个时间单位的迁移惩罚。多队列不偷工作；单队列谁闲谁取。

## 实验步骤

1. 运行：

```bash
python3 02-virtualization/ch10-multiprocessor-scheduling/multicpu.py
```

2. 记录三种策略的完成时间和迁移惩罚：多队列、单队列且时间片为 12、单队列且时间片为 4。

## 实验结果

```text
三个作业缓存都在 CPU0，迁移一次额外付出 5
  多队列、不迁移：完成时间 36，迁移惩罚 0
  单队列、整段运行：完成时间 24，迁移惩罚 5
  单队列、时间片 4：完成时间 31，迁移惩罚 20
通过：亲和性和负载均衡是一对矛盾，短时间片会放大迁移代价
```

## 结果说明

多队列把三份工作都留在 CPU0，惩罚是 0，完成时间是 12×3=36，另一颗核闲着。单队列整段运行只把一个作业迁走一次，惩罚 5，完成时间降到 24。时间片改成 4 以后，作业反复离开热缓存，惩罚升到 20，完成时间反弹到 31，比整段运行更差。
