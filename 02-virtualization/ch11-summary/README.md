# 第 11 章 小结（CPU 虚拟化）

把这一半的数量关系再算一遍：进程加上受限直接执行是机制，调度是策略。

## 实验步骤

1. 运行：

```bash
python3 02-virtualization/ch11-summary/summary.py
```

2. 用手算核对。三份作业长度为 100、10、10，都在 t=0 到达。长作业先跑时，完成时刻是 100、110、120。短作业先跑时，完成时刻是 10、20、120。

## 实验结果

```text
CPU 虚拟化
  机制：进程 + 受限直接执行（用户态直接跑，陷入后内核才调度）
  策略：调度器挑选就绪进程
  同样三份作业 100/10/10，长作业先跑的平均周转时间 110
  短作业先跑则是 50
  RR 不改变等长作业的平均周转时间，但把第一次响应拉到一个时间片以内
  多核调度还要付缓存迁移的代价，所以不能只看负载是否平均
通过
```

## 结果说明

`(100+110+120)/3 = 110`，`(10+20+120)/3 = 50`。和第 7 章仿真一致。等长作业上 RR 的平均周转时间可以和 FIFO 相同，它换来的是响应时间。多核上还要加上第 10 章测到的迁移惩罚，完成时间短并不自动等于代价小。
