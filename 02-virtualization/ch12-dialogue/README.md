# 第 12 章 对话

CPU 的虚拟化讲完了。这一章改问内存：进程看到的地址是不是已经分成代码、堆和栈。实验直接读当前进程的地址空间映射。

## 实验步骤

1. 执行：

```bash
awk 'NR<=8 {print}' /proc/self/maps
```

2. 找出带 `r-xp` 的可执行映射，以及标成 `[heap]` 的那一行。再运行第 13 章的 `aspace`，核对代码地址低于堆、堆低于栈。

## 实验结果

这次 `awk` 打印的是它自己的映射，前几行是：

```text
5642f29cc000-5642f29ce000 r--p ... /usr/bin/mawk
5642f29ce000-5642f29ed000 r-xp ... /usr/bin/mawk
5642f29ed000-5642f29f5000 r--p ... /usr/bin/mawk
5643263ef000-564326410000 rw-p ... [heap]
```

第 13 章同一次机器上的指针比较是：代码 `0x56116c94d2db` < 堆 `0x5611a285f2a0` < 栈 `0x7ffd60e81eb4`。具体地址每次都变，次序不变。

## 结果说明

可执行文件被映射成几段权限不同的区间，堆单独长在后面。这些虚拟地址还没有变成物理地址，翻译从第 15 章开始。
