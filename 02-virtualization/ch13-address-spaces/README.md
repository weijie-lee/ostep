# 第 13 章 Address Spaces

打印代码、静态数据、堆和栈的地址，再用递归看栈往哪边长。

## 实验步骤

1. 编译并运行：

```bash
make
./build/02-virtualization/ch13-address-spaces/aspace
```

2. 核对三件事：`main` 的地址低于 `malloc`，`malloc` 低于栈上的局部变量；递归深度每加 1，局部变量地址下降；程序打印“通过”。

## 实验结果

```text
代码   main        0x56116c94d2db
静态   global_data 0x56116c950010
静态   global_bss  0x56116c95002c
堆     malloc      0x5611a285f2a0
栈     stack_local 0x7ffd60e81eb4
递归调用，观察栈帧：
  栈深度 0  局部变量地址 0x7ffd60e81e8c
  栈深度 1  局部变量地址 0x7ffd60e81e4c
  栈深度 2  局部变量地址 0x7ffd60e81e0c
  栈深度 3  局部变量地址 0x7ffd60e81dcc
  栈深度 4  局部变量地址 0x7ffd60e81d8c
通过：一个进程看到的是连续私有地址，实际由后面的翻译机制映射到物理内存
```

地址每次不同。这次相邻栈帧相差 `0x40` 字节。

## 结果说明

静态变量紧挨着代码。堆在两者之上。栈在用户空间的高地址，向低地址增长：`0x...1e8c`、`0x...1e4c`、`0x...1e0c`、`0x...1dcc`、`0x...1d8c`。进程把这些都看成自己的线性地址，物理页由后面的翻译填上。
