# 第 14 章 Memory API

`malloc` / `free` 是用户态接口。这个包装器给每次分配记账，用来抓住重复释放和泄漏，不让进程真的崩溃。

## 实验步骤

1. 运行：

```bash
make
./build/02-virtualization/ch14-memory-api/memapi
```

2. 程序会分配 32 字节和 16 字节，只释放 16 字节那块，并且把同一指针再释放一次。确认输出里有 1 次拒绝重复释放、1 次 32 字节泄漏。

## 实验结果

```text
memapi: malloc 两块，正常释放其中一块
memapi: 拒绝重复释放 0x55b00a1852d0
memapi: 泄漏 0x55b00a1852a0 （32 字节）
通过：接口很薄，错误用法要靠约定或者这种记账才能早发现
```

指针值每次不同。字节数和次数不变。

## 结果说明

16 字节那块被释放两次，第二次没有再交给 libc 的 `free`，所以不会触发堆损坏。32 字节那块一直标记为存活，结束时被报成泄漏。接口本身不检查这两件事，检查来自包装器里的表。
