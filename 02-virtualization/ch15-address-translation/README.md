# 第 15 章 Address Translation

最简单的翻译硬件是基址加界限。物理地址 = 虚拟地址 + 基址。虚拟地址必须落在 `[0, 界限)`。

本实验把进程放在物理地址 16384，界限 4096。

## 实验步骤

1. 运行：

```bash
python3 02-virtualization/ch15-address-translation/base_bounds.py
```

2. 用手算三笔：`0+16384`、`100+16384`、`4095+16384`。再确认 4096 被拒绝。

## 实验结果

```text
基址 16384，界限 4096
  VA    0 -> PA 16384
  VA  100 -> PA 16484
  VA 4095 -> PA 20479
  VA 4096 越界：虚拟地址 4096 不在 [0, 4096)
通过：重定位靠基址，隔离靠界限
```

## 结果说明

`20479 = 16384 + 4095`，这是这块地址空间里最后一个合法字节。4096 等于界限，不算合法。基址负责把进程搬到物理内存的另一处，界限负责不让它碰到外面。
