# 第 16 章 Segmentation

代码、堆、栈各有自己的基址和长度。代码和堆向高地址长，栈从段空间的顶端向低地址长。

段的设置：代码基址 `0x1000`、已用 `0x100`；堆基址 `0x8000`、已用 `0x40`；栈基址 `0x20000`、段空间 `0x1000`、已用最高处的 `0x20` 字节。

## 实验步骤

1. 运行：

```bash
python3 02-virtualization/ch16-segmentation/segmentation.py
```

2. 核对四个翻译结果，并确认两次越界都被拒绝：栈偏移 `0x1000-0x21=4063`，堆偏移 `0x40`。

## 实验结果

```text
代码 VA 偏移 0x10 -> PA 0x1010
堆   VA 偏移 0x20 -> PA 0x8020
栈顶 VA 偏移 0xfff -> PA 0x20fff
栈已用的最低偏移 -> PA 0x20fe0
栈再往下访问被拒绝：栈 偏移 4063 越过反向界限
堆越过已分配长度被拒绝：堆 偏移 64 越过正向界限 64
通过：每段独立重定位；栈用反向界限，中间的洞不必分配物理内存
```

## 结果说明

正向段就是基址加偏移：`0x1000+0x10=0x1010`，`0x8000+0x20=0x8020`。栈顶偏移 `0xfff` 落到 `0x20000+0xfff=0x20fff`。已用 32 字节时，最低合法偏移是 `0x1000-0x20=0xfe0`，物理地址 `0x20fe0`。再低一个字节就被反向界限拦住。堆和栈之间的洞不用分配物理页。
