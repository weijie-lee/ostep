# 第 19 章 Translation Lookaside Buffers

TLB 有 4 项，全相联，按最近使用替换。页表把虚拟页 `v` 映射到帧 `v+10`。

## 实验步骤

1. 运行：

```bash
python3 02-virtualization/ch19-tlb/tlb.py
```

2. 三次实验：
   - 把页 0 和页 1 的序列 `(0,0,1,1)` 重复 3 遍
   - 依次访问页 0 到页 7，每页只出现一次
   - 先装入进程 1 的页 3，切到进程 2，再切回进程 1；对照切换时清空 TLB 的做法

## 实验结果

```text
顺序反复访问两页：命中 10，未命中 2
每次换一页、TLB 只有 4 项：命中 0，未命中 8
没有 ASID、切换时清空：第二次仍未命中（未命中次数 2）
通过：TLB 把页表翻译缓存住；ASID 让两个地址空间的项共存
```

带 ASID 的那次：未命中 2、命中 1。清空之后同一页的未命中次数是 2。

## 结果说明

12 次访问里只有页 0 和页 1 的第一次是未命中，所以命中 10、未命中 2。八个不同的页互不重复，4 项的 TLB 也帮不上，8 次全是未命中。ASID 让进程 1 的页 3 在切走之后还留在 TLB 里，切回来是命中；没有 ASID 就得清空，同一页再付一次未命中。
