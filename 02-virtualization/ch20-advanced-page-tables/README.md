# 第 20 章 Advanced Page Tables

虚拟地址分成 4 位页目录、4 位页表、8 位偏移。线性页表要 `2^8=256` 项。实验只映射三个虚拟页，其中两个落在同一个页目录项里。

## 实验步骤

1. 运行：

```bash
python3 02-virtualization/ch20-advanced-page-tables/multilevel.py
```

2. 核对占用项数：页目录 16 项，加上 2 张各 16 项的二级表。再核对 `VA 0x231f` 的物理地址。未映射的地址 0 应当缺页。

## 实验结果

```text
线性页表项数 256
两级页表实际占用项数 48（页目录 16 项 + 2 张二级表）
VA 0x231f -> PA 0x051f
未映射地址缺页：PDE 0 PTE 0 无效
通过：页目录项无效就不必为那一整段分配页表
```

## 结果说明

48 项对 256 项，稀疏地址空间不用为没碰过的目录项分配二级表。`0x231f` 的虚拟页是 `0x23`，页目录索引 2、页表索引 3，这一项映射到帧 5。偏移是 `0x1f`，所以物理地址是 `(5 << 8) | 0x1f = 0x051f`。
