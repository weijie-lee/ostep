# 第 21 章 Swapping: Mechanisms

只有 1 个物理帧。先写入虚拟页 0，再换出它，访问虚拟页 1，最后把虚拟页 0 换回来。换出哪一页由调用者指定，这一章只记录缺页和磁盘传输。

## 实验步骤

1. 运行：

```bash
python3 02-virtualization/ch21-swapping-mechanisms/swap.py
```

2. 记下三次访问各自的缺页、写盘和读盘。预期总数是缺页 3、写盘 1、读盘 1。

## 实验结果

```text
写入 VPN 0：缺页 1，脏位 True，帧 0
换出 VPN 0 再访问 VPN 1：写盘 1，读盘 0
VPN 0 再换入：读盘 1，存在位 True，脏位 False
通过：不存在的页触发缺页；脏页离开内存前写回交换区；干净页可以只丢掉
```

## 结果说明

虚拟页 0 第一次写入是缺页，帧里没有旧内容，所以不读盘，写入后脏位为真。把它换出时必须写盘一次。虚拟页 1 只是读取，换出时是干净的，不写盘。虚拟页 0 再进来要从交换区读一次，读入后的脏位是假，直到再次被写。
