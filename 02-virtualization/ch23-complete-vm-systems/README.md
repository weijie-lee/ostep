# 第 23 章 Complete Virtual Memory Systems

3 个物理帧，TLB 2 项，替换用 Clock。先反复访问虚拟页 0 和 1，再写入页 0，然后访问页 2、3、4。

## 实验步骤

1. 运行：

```bash
python3 02-virtualization/ch23-complete-vm-systems/vm.py
```

2. 分开看热身阶段和扩大工作集之后的命中、未命中、缺页和写回次数。热身应当只有 2 次缺页。

## 实验结果

```text
工作集热身：TLB 命中 4，缺页 2
扩大工作集之后：TLB 命中 5，TLB 未命中 5，缺页 5，脏页写回 1
仍在内存的虚拟页 [2, 3, 4]
通过：一次访存先问 TLB，再问页表，最后才可能访问磁盘
```

## 结果说明

页 0 和页 1 第一次进入内存各缺页一次，后面 4 次打在 TLB 上。工作集扩大到装不下时又缺页 3 次，总数变成 5。页 0 被写过，Clock 把它换出前写回 1 次。结束时内存里只剩 2、3、4，页 0 和页 1 已经不在帧里。
