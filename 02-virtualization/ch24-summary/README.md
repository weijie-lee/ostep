# 第 24 章 小结（内存虚拟化）

算一笔页表的空间账。32 位地址、4 KiB 的页，虚拟页有 `2^20` 个。页表项按 4 字节计。

## 实验步骤

1. 运行：

```bash
python3 02-virtualization/ch24-summary/summary.py
```

2. 用手算：线性页表 `2^20 × 4` 字节是多少 KiB。两级页表如果只用到 1 个页目录项和 1 张 1024 项的二级表，项数是 `(1+1)×1024`。

## 实验结果

```text
内存虚拟化
  抽象：每个进程一块私有地址空间
  翻译：分页把虚拟页号换成物理帧号
  线性页表覆盖 2^20 个虚拟页、每项 4 字节，就要 4096 KiB
  进程实际只用 32 页时，一张二级表加页目录大约 8 KiB
  TLB 让重复翻译不再访问内存；Clock 在帧不够时挑牺牲页
通过
```

## 结果说明

`2^20 × 4 / 1024 = 4096 KiB`，线性页表本身就要 4 MiB。两级结构在这个例子里是 `2 × 1024 × 4 = 8 KiB`。进程只用 32 页时，不该为整个地址空间付出 4 MiB 的页表。TLB 和 Clock 是前面两章已经测过的速度和替换部分。
