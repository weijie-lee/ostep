# 第 25 章 对话

共享地址空间之后，线程数会远多于 CPU 数。这一章先数线程，丢更新的实验放在第 26 章，因为那里用屏障把交错固定住了。

## 实验步骤

1. 执行：

```bash
nproc
ps -eL --no-headers | wc -l
```

2. 然后运行第 26 章的 `race`，看没有锁时两个线程把同一次自增写成了 1。

## 实验结果

本次采样：

```text
nproc=4
轻量级进程（线程）数=127
```

第 26 章的对应结果是：无锁 `shared=1`，加锁 `shared=2`。线程个数会随系统变化，它大于 CPU 数这一点不变。

## 结果说明

4 个核上有一百多个线程，调度仍然是第 7 章那一类问题。新问题是这些线程能写同一块内存。只数线程看不到数据竞态，所以下一章把两次读改写卡在同一时刻。
