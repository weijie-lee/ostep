# 第 26 章 Concurrency and Threads

两个线程用屏障对齐：都读到 `shared`，都把它加上 1，再都写回去。然后用互斥锁把同样的自增包进临界区。

## 实验步骤

1. 编译并运行：

```bash
make
./build/03-concurrency/ch26-threads/race
```

2. 第一次的初值是 0。确认无锁结果是 1，加锁结果是 2。

## 实验结果

```text
无锁：两个线程都读到 0，都写回 1，最终 shared=1
互斥锁：临界区里的自增不能交错，最终 shared=2
通过：共享数据需要原子地读改写
```

## 结果说明

屏障让两个线程读到同一个 0，各自算出 1，后写回去的那个把另一个的更新盖掉，所以 0+1+1 变成了 1。互斥锁让两次自增串行，结果是 2。这次没有靠碰运气的调度，交错是程序自己排好的。
