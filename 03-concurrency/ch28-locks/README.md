# 第 28 章 Locks

4 个线程各把计数器加 20000 次。先用测试并设置锁，再用票锁。两种锁的总数都应当是 80000。

## 实验步骤

1. 运行：

```bash
make
./build/03-concurrency/ch28-locks/locks
```

2. 核对两个 `counter=`。测试并设置那段还会打印最先进入临界区的线程号，那个顺序不要求每次相同。

## 实验结果

```text
测试并设置锁：counter=80000，先进入临界区的线程 0 0 0 0
票锁：counter=80000（取号顺序就是进入顺序，不会饿死）
通过
```

## 结果说明

`4 × 20000 = 80000`。测试并设置用一条原子交换抢标志，这次连续四次都是线程 0 先拿到，说明它不保证先来后到。票锁用 `fetch_add` 取号，按号进入，计数结果同样正确，公平性来自号的顺序而不是谁自旋赢了。
