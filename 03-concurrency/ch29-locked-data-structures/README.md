# 第 29 章 Locked Data Structures

两个实验：近似计数器，以及一把锁保护的链表。

近似计数器有 4 个线程，每个加 100000 次，阈值 1024。链表有 4 个线程，每个插入 50 个不重复的键。

## 实验步骤

1. 运行：

```bash
make
./build/03-concurrency/ch29-locked-data-structures/counter
./build/03-concurrency/ch29-locked-data-structures/list
```

2. 计数器结束前，全局值加上各线程手里的余数应当等于 400000，全局值应当是 1024 的倍数。链表应当 200 个键全部能找到。

## 实验结果

```text
精确计数（每次都抢全局锁）= 400000
近似计数尚未刷入的全局值 = 397312，各线程手里还握着 2688
把局部计数刷进全局之后 = 400000
通过：读全局值可以稍旧，但误差有上界

并发插入 200 个键，查找命中 200 个
通过：锁盖住了“改头指针”和“沿链表走”这两段临界区
```

## 结果说明

`100000 ÷ 1024 = 97` 余 672，四个线程手里一共 `4 × 672 = 2688`。已经刷进全局的是 `400000 - 2688 = 397312`，能被 1024 整除。只读全局值会少 2688，误差不超过 `4 × 1023`。链表在插入和遍历时都拿着同一把锁，200 次查找全部命中。
