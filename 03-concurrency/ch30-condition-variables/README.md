# 第 30 章 Condition Variables

一个生产者、一个消费者，缓冲区 4 格，传递整数 0 到 19。等待条件写在 `while` 里。

## 实验步骤

1. 运行：

```bash
make
./build/03-concurrency/ch30-condition-variables/prodcons
```

2. 消费者读出的序列应当是 `0, 1, ..., 19`。程序内部逐项检查，失败会非零退出。

## 实验结果

```text
生产者写入 0..19，消费者按原顺序读出，缓冲区只有 4 格
通过：while 在被叫醒后重新检查缓冲区是否真的有数据
```

## 结果说明

20 个数通过只有 4 格的缓冲区，而且顺序没变，说明生产者在缓冲区满时睡着、消费者在空时睡着。`while` 在被 `signal` 叫醒后重新看 `count`，不会在条件已经失效时取数据。`if` 会出错的调度放在附录的管程实验里，那里余额会变成 -1。
