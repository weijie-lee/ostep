# 第 35 章 对话

断电之后还在的数据放在块设备上，由文件系统组织。先看这台机器的磁盘和根文件系统，再进入第 36 章的传输模型。

## 实验步骤

1. 执行：

```bash
lsblk -d -o NAME,ROTA,TYPE
df -T /
```

2. 记下根文件系统的类型和所在设备。虚拟机里的磁盘可能把 `ROTA` 报成 1，这不代表它真是机械盘。

## 实验结果

本次采样：

```text
NAME ROTA TYPE
vda     1 disk
vdb     1 disk
vdc     1 disk

/dev/vdc  ext4  265592036  7306984  258268668  3% /
```

容量数字会变。这次根目录是 ext4，在 `/dev/vdc` 上。

## 结果说明

进程退出后，第 2 章那个临时文件之所以还能被读回，是因为它落在这种块设备上的文件系统里。后面先算一次 I/O 要占多少 CPU，再算磁盘寻道，然后才实现一个很小的文件系统。
