# 第 36 章 I/O Devices

传输 100 字节，比较轮询、中断驱动和 DMA 各占用多少 CPU。

## 实验步骤

1. 运行：

```bash
python3 04-persistence/ch36-io-devices/io.py
```

2. 三种方式的设备忙时间都应当是 100。CPU 忙的时间应当是轮询 > 中断 > DMA。

## 实验结果

```text
传输 100 字节
  编程 I/O（轮询）: CPU 忙 100  其他工作   0  设备忙 100
  中断驱动: CPU 忙  51  其他工作  50  设备忙 100
  DMA: CPU 忙   2  其他工作  98  设备忙 100
通过：中断和 DMA 把等待设备的时间还给别的进程
```

## 结果说明

轮询时 CPU 亲自搬每个字节，100 个时间单位都不能做别的事。中断驱动让设备先准备一半时间，CPU 在这 50 个单位里可以跑别的进程，然后花 50 个单位拷贝，再加上 1 次中断处理，CPU 忙 51。DMA 只在启动和完成时打扰 CPU，CPU 忙 2，其余 98 可以做别的工作。
