# 第 37 章 Hard Disk Drives

教学磁盘：每磁道 8 个扇区，每个扇区 1 ms。寻道时间 = `2 + 0.1 × 磁道距离`（毫秒）。寻道期间盘片继续转。

单次请求：磁头在磁道 0、扇区 0，目标是磁道 10、扇区 0，读 1 个扇区。

调度请求：磁头在磁道 20，请求磁道依次是 10、40、5。SCAN 先向上。

## 实验步骤

1. 运行：

```bash
python3 04-persistence/ch37-hard-disk-drives/disk.py
```

2. 先核对单次请求是不是 9.0 ms：寻道 `2+0.1×10=3`，转过 3 个扇区后还要等 5 个扇区，再加 1 ms 传输。再核对四种调度的顺序和寻道距离。

## 实验结果

```text
单次请求：磁道 0→10，目标扇区 0，服务时间 9.0 ms
  寻道 3.0 ms 期间盘片转过 3 个扇区，再等 5 个扇区，传输 1 个扇区
磁头在 20，请求磁道 [10, 40, 5]
  FCFS    顺序 [10, 40, 5]  寻道距离 75
  SSTF    顺序 [10, 5, 40]  寻道距离 50
  SCAN    顺序 [40, 10, 5]  寻道距离 55
  C-SCAN  顺序 [40, 5, 10]  寻道距离 60
通过
```

## 结果说明

`3+5+1=9`。FCFS 的寻道是 `|20-10|+|10-40|+|40-5|=75`。SSTF 先去最近的 10，再去 5，最后去 40，距离 50。SCAN 先到 40 再折返，距离 55。C-SCAN 到 40 后从低磁道重新向上，顺序是 40、5、10，距离 60。这组请求上 SSTF 最短，但不保证对所有请求队列都公平。
