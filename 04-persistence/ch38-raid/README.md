# 第 38 章 RAID

每块盘 100 个块。看 RAID-0/1/4/5 把逻辑块 5 放到哪，再对条带 `[1, 2, 3, 4]` 做一次把第 0 号数据改成 7 的小写入。

## 实验步骤

1. 运行：

```bash
python3 04-persistence/ch38-raid/raid.py
```

2. 核对容量：RAID-0 是 400，RAID-1 是 100，RAID-4 和 RAID-5 都是 400。小写入应当正好 4 次 I/O，新校验是 2。

## 实验结果

```text
RAID-0 块 5 / 4 盘 -> 磁盘 (1, 1)，容量 400
RAID-1 块 5 -> 两份副本 [(0, 5), (1, 5)]，容量 100
RAID-4 块 5 / 5 盘 -> (数据盘, 偏移, 校验盘) (1, 1, 4)，容量 400
RAID-5 前 8 个逻辑块的 (数据盘, 条带, 校验盘):
  块 0: (1, 0, 0)
  块 1: (2, 0, 0)
  块 2: (3, 0, 0)
  块 3: (4, 0, 0)
  块 4: (0, 1, 1)
  块 5: (2, 1, 1)
  块 6: (3, 1, 1)
  块 7: (4, 1, 1)
小写入：读旧数据 -> 读旧校验 -> 写新数据 -> 写新校验，新校验 2
通过
```

## 结果说明

RAID-0 把块 5 放在 `5 % 4 = 1` 号盘、偏移 `5 // 4 = 1`。RAID-1 两块盘都放一份。RAID-4 的校验盘固定是 4 号盘。RAID-5 的校验盘随条带转动：第 0 条在 0 号盘，第 1 条在 1 号盘，所以逻辑块 4 的数据落到 0 号盘。小写入的新校验是 `1^2^3^4^1^7 = 2`，和把整条重算 `7^2^3^4` 相同，但只要 4 次 I/O，不用读整条带。
