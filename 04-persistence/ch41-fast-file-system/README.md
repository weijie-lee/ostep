# 第 41 章 Fast File System

8 个柱面组。新目录放到目录数量最少的组。小文件跟目录走。大文件的前 4 块留在目录那一组，后面的块逐组散开。

## 实验步骤

1. 运行：

```bash
python3 04-persistence/ch41-fast-file-system/ffs.py
```

2. 第一个目录应当在组 0，第二个在组 1。2 块的小文件应当是 `[0, 0]`。7 块的大文件应当是 `[0, 0, 0, 0, 1, 2, 3]`。

## 实验结果

```text
第一个目录在组 0，第二个目录在组 1
小文件的块落在 [0, 0]
大文件的块落在 [0, 0, 0, 0, 1, 2, 3]
通过：局部性给小文件，分散放置避免大文件占满一个柱面组
```

## 结果说明

两个目录没有挤在同一组，所以读不同目录时寻道更分散。小文件和目录同组，读目录再读文件可以少寻道。大文件如果 7 块都留在组 0，会把这一组占满，所以从第 5 块起放到组 1、2、3。
