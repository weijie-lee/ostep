# 第 44 章 Flash-based SSDs

两块闪存、每块 4 页。先写入逻辑页 0、1、2、3 的 `v0-*`，再覆盖 0、1、2 为 `v1-*`，然后把逻辑页 0 再写成 `v2-0` 和 `v3-0`。最后一次写入会触发垃圾回收。

## 实验步骤

1. 运行：

```bash
python3 04-persistence/ch44-flash-ssds/ssd.py
```

2. 核对四个逻辑页的最新值，以及主机写入次数、闪存编程次数和擦除次数。闪存编程应当多于主机写入。

## 实验结果

```text
逻辑页 0 = v3-0，仍未覆盖的逻辑页 3 = v0-3
主机写入 9，闪存编程 10，各块擦除次数 [1, 0]
通过：逻辑覆盖变成异地编程；擦除才让页回到可写状态
```

同时读到的另外两页是：逻辑页 1 = `v1-1`，逻辑页 2 = `v1-2`。

## 结果说明

主机写入 4 次初值、3 次 `v1`、2 次继续覆盖页 0，共 9 次。空页用完后，第一块上还有有效的逻辑页 3，垃圾回收把它抄到擦除后的空页，这就是多出来的第 10 次编程，写放大是 `10/9`。擦除次数 `[1, 0]` 表示只有第一块被擦过。逻辑页 3 没有被覆盖，所以仍是 `v0-3`。
