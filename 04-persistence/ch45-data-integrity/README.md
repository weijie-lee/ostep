# 第 45 章 Data Integrity and Protection

数据是三个字节 `01 01 02`。先翻转第 0 字节的最低位，再把第 0 和第 1 字节的最低位一起翻转。分别用异或校验和带位置的校验检查。

## 实验步骤

1. 运行：

```bash
python3 04-persistence/ch45-data-integrity/checksum.py
```

2. 单比特错误两种校验都应当发现。成对翻转时，异或应当失败（发现不了），带位置的校验应当成功发现。

## 实验结果

```text
原数据 010102  异或校验 2  带位置的校验 9
翻转 1 个比特：异或发现 True，位置校验发现 True
翻转两个相同的低比特：异或发现 False，位置校验发现 True
通过：校验失败就不要把这块数据交给上层
```

## 结果说明

异或值是 `0x01 ^ 0x01 ^ 0x02 = 0x02`。只翻转一个最低位会改变这个值。两个相同的最低位一起翻转，异或结果不变，所以发现不了。带位置的校验是 `(1×1 + 2×1 + 3×2) = 9`，两个字节的位置系数不同，成对翻转后变成 6，能被发现。校验失败就丢弃这块数据，它本身不负责改正。
