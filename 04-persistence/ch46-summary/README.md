# 第 46 章 小结（持久化，单机部分）

把单机存储的三笔账放在一起：服务时间的组成、RAID-5 的容量、小写入的 I/O 次数。

## 实验步骤

1. 运行：

```bash
python3 04-persistence/ch46-summary/summary.py
```

2. 用第 37 章的 9.0 ms、第 38 章的 4 次 I/O 和第 42 章的重做结果对照这三句话。

## 实验结果

```text
单机持久化
  服务时间 = 寻道 + 旋转 + 传输
  RAID-5 用 5 块盘得到 4 块盘的容量
  小写入要 4 次 I/O：读旧数据、读旧校验、写新数据、写新校验
  提交记录写到之后，日志重做才是安全的；重做必须幂等
通过
```

## 结果说明

5 块盘里 1 块的容量给校验，可用容量是 4 块盘。小写入的 4 次 I/O 就是第 38 章那条 `读旧数据 -> 读旧校验 -> 写新数据 -> 写新校验`。日志只有在提交记录落盘之后才重做，并且第 42 章已经把同一条事务重做了两次，结果仍是 `NEW`。
