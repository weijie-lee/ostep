# 第 47 章 对话

单机文件解决不了“请求发出去之后没有应答”。实验用第 48 章的转账：第一次调用已经入账，应答丢了，客户端又发一次。

## 实验步骤

1. 运行：

```bash
python3 04-persistence/ch48-distributed-systems/rpc.py
```

2. 只看两个余额。没有请求编号时应当是 20，有请求编号时应当是 10。

## 实验结果

```text
没有请求编号：应答丢失后重试，余额变成 20
带请求编号：第二次被认成重复调用，余额保持 10
通过：超时重试之前，要先决定重复执行是否可以接受
```

## 结果说明

两次都是“加 10”。服务器如果什么都不记，重试会再加一次，10 变成 20。请求编号 7 被记住之后，第二次直接返回上一次的结果，余额停在 10。NFS 和 AFS 是把这个取舍做到文件协议里的两种办法。
