# 第 48 章 Distributed Systems

客户端调用一次“加 10”。服务器已经做完，应答在回来的路上丢了，客户端再发一次。比较不带请求编号和带编号 7 的两种服务器。

## 实验步骤

1. 运行：

```bash
python3 04-persistence/ch48-distributed-systems/rpc.py
```

2. 余额应当分别是 20 和 10。

## 实验结果

```text
没有请求编号：应答丢失后重试，余额变成 20
带请求编号：第二次被认成重复调用，余额保持 10
通过：超时重试之前，要先决定重复执行是否可以接受
```

## 结果说明

不带编号的服务器每收到一次就 `balance += 10`，两次投递得到 20，这是至少一次。带编号的服务器把请求 7 的结果存下来，第二次发现 `7` 已经在表里，不再加钱，余额保持 10，这是至多一次。调用方要先决定重复执行能不能接受，再选择超时之后是否重试。
