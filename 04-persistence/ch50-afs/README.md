# 第 50 章 Andrew File System (AFS)

文件从版本 1、内容 `v1` 开始。Alice 和 Bob 都打开并拿到回调。实验做两轮：第一轮回调送得到，第二轮回调被丢掉。

## 实验步骤

1. 运行：

```bash
python3 04-persistence/ch50-afs/afs.py
```

2. 第一轮：Bob 写回 `v2` 后，通知名单里应当有 `alice`，Alice 再读缓存应当失败，重新打开后读到 `v2`。第二轮：送达名单是空的，Alice 拿版本 1 去写应当被拒绝，服务器上仍是 `v2`。

## 实验结果

```text
Bob 关闭并写回 v2，服务器通知 ['alice']
Alice 的缓存被作废：回调已撤销，必须重新打开
Alice 重新打开，读到 b'v2'
回调被丢掉，实际送达 []，Alice 仍认为版本是 1
服务器拒绝覆盖：alice 基于版本 1 写入，服务器已经是 2
通过：回调让缓存失效；版本号挡住丢失的回调
```

## 结果说明

AFS 在打开时把整个文件给客户端，并记下回调。Bob 的 `store` 把版本从 1 加到 2，同时通知 Alice。Alice 的缓存被标成无效，不能继续读旧内容，重新打开才取到 `v2`。回调如果没送到，Alice 还拿着版本 1，服务器用版本号拒绝这次覆盖，磁盘上仍然是 Bob 写入的 `v2`。
