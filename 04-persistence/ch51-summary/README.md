# 第 51 章 小结（分布式文件）

把两种一致性时机并排放：NFS 是 close-to-open，AFS 是回调。

## 实验步骤

1. 运行：

```bash
python3 04-persistence/ch51-summary/summary.py
```

2. 用第 49 章 Alice 没重新打开时读到的 `v1`，和第 50 章收到回调后缓存失效，对照这两句。

## 实验结果

```text
分布式持久化
  应答丢失时，盲目重试 = 至少一次；记住请求号 = 至多一次
  NFS：服务器无状态，客户端在每次 open 时重新取属性
  AFS：打开时取整个文件，服务器用回调通知缓存作废
通过
```

## 结果说明

第 48 章的余额已经把“至少一次得到 20、至多一次得到 10”跑出来了。NFS 不在服务器上记打开状态，所以 Alice 必须再次 `open` 才看见 `v2`。AFS 记着回调，Bob 一写完就能通知 Alice 把缓存丢掉。两种协议看见新数据的时机不同。
