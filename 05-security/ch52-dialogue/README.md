# 第 52 章 对话

安全部分先问“你是谁”。实验读取当前进程的用户身份，后面的认证和访问控制都从这里分开。

## 实验步骤

1. 执行：

```bash
id
```

2. 记下 uid。然后做第 54 章，确认口令本身不会被存下来；再做第 55 章，看同一个 uid 在模式 `0640` 下能读什么。

## 实验结果

本次采样：

```text
uid=1000(ubuntu) gid=1000(ubuntu) groups=1000(ubuntu),4(adm),20(dialout),24(cdrom),25(floppy),27(sudo),29(audio),30(dip),44(video),46(plugdev)
```

用户名和组会随机器变化。这次的 uid 是 1000。

## 结果说明

`id` 给出的是内核认可的 uid/gid，不是口令。口令用来在登录时把一个人映射成这个 uid，映射完成之后访问控制看的是 uid、组和凭证。第 53 章接着问：一个特权程序替别人干活时，该用自己的 uid 还是调用者的 uid。
