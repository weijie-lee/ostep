# 第 54 章 Authentication

用 PBKDF2-HMAC-SHA256 把口令 `correct horse` 变成摘要，迭代 2000 次。盐是 16 字节随机数。实验只校验程序自己刚生成的摘要，不读取任何真实口令库。

## 实验步骤

1. 运行：

```bash
python3 05-security/ch54-authentication/auth.py
```

2. 核对三个布尔结果：两次摘要不同；原盐加正确口令得到 True；原盐加 `wrong horse` 得到 False。十六进制前缀每次都变。

## 实验结果

一次运行的输出是：

```text
同一口令，盐不同，摘要也不同：5a28b841f9eeb041... 对比 4cb468d1f0ea1825...
用原来的盐校验正确口令：True
用原来的盐校验错误口令：False
通过：数据库里只存盐和摘要，不存口令本身
```

## 结果说明

同一个口令配两个盐，摘要的前 8 字节分别是 `5a28b841f9eeb041` 和 `4cb468d1f0ea1825`，它们不相同。校验时用当初的盐再算一次，并用常数时间比较。错误口令即使盐正确也得不到 True。数据库里需要留下的是盐和摘要，不是口令。
