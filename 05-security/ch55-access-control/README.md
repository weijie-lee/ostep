# 第 55 章 Access Control

三件事放在同一次运行里：Unix 模式 `0640`、一张只给 bob 读权利的 ACL、一张随机签发的能力凭证。

文件主人 uid=1000、gid=2000。调用者分别是主人 `(1000,1000)`、同组 `(1001,2000)` 和其他人 `(1002,1002)`。

## 实验步骤

1. 运行：

```bash
python3 05-security/ch55-access-control/acl.py
```

2. `0640` 的四个布尔值应当是主人读真、同组读真、同组写假、其他人读假。bob 能读不能写。出示原件为真，伪造的 16 个 0 为假。

## 实验结果

```text
模式 0640：主人读 True，同组读 True，同组写 False，其他人读 False
ACL：bob 读 True，bob 写 False
能力：出示原件 True，伪造 False
通过：名单检查的是主体，能力检查的是凭证
```

## 结果说明

`0640` 是主人 `rw-`、同组 `r--`、其他人 `---`。同组调用者因此能读不能写。ACL 按用户名列权利，bob 的集合里只有 `read`。能力不看你是谁，只看出示的字符串是否等于签发时的那一串；全 0 的字符串对不上。
