# 第 57 章 Distributed Systems Security

同一条编号为 100 的消息送两次。一台服务器不记编号，另一台记下见过的编号。

## 实验步骤

1. 运行：

```bash
python3 05-security/ch57-distributed-security/replay.py
```

2. 不记编号时两次都应当被接受，入账 2 次。记住编号时第二次应当被拒绝，入账 1 次。

## 实验结果

```text
不记编号：第一次 True，原样再送一次 True，入账 2 次
记住编号：第一次 True，再送一次 False，入账 1 次
通过：分布式认证还要回答这条消息是不是刚才那条的拷贝
```

## 结果说明

编号 100 第一次两边都接受。不记编号的服务器把第二次也当成新消息，入账次数变成 2。记住编号的服务器在集合里看见 100，返回 False，入账次数停在 1。这个编号只回答“是不是刚才那条的拷贝”，它不代替第 56 章的 HMAC。
