# 附录：管程

缓冲区里只有 1 个元素，Mesa 语义的 `signalAll` 把两个正在等的消费者都唤醒。比较醒来之后用 `if` 和用 `while`。

## 实验步骤

1. 运行：

```bash
python3 06-appendices/monitors/mesa.py
```

2. `if` 的余额应当是 -1，`while` 的余额应当是 0。第 30 章的有界缓冲区用的是 `while`。

## 实验结果

```text
Mesa + if：缓冲区余额 -1（第二个消费者醒来后没有再看一眼）
Mesa + while：缓冲区余额 0，另一个消费者继续等
通过：被叫醒只说明刚才也许满足过，不说明现在仍满足
```

## 结果说明

生产者放入 1 个元素并唤醒 A 和 B。A 取走唯一的元素。B 如果不再检查，会再取一次，余额记成 -1。B 如果用 `while` 再看一眼，发现缓冲区已经空，就继续等，余额是 0。
