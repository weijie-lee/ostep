# 附录：xv6 实验

xv6 是一套可以读完的教学操作系统。书里的 xv6 实验让你改内核，而不是在用户态模拟。本仓库不内嵌 xv6 源码。各实验和章节的对应关系是：

| xv6 实验 | 本书章节 |
| --- | --- |
| 工具和系统调用 | 第 5 章 Process API、第 39 章文件 |
| 页表 | 第 18–20 章 |
| 陷入和中断 | 第 6 章受限直接执行 |
| 写时复制 | 第 21 章交换机制里的缺页路径 |
| 线程和锁 | 第 26–31 章 |
| 文件系统 | 第 40–42 章 |
| 网络 | 第 48 章 |

用户态能看清的那一部分，用本仓库对应章节的演示。要改页表、陷入和磁盘日志的内核路径时，再去读 xv6 本身。
