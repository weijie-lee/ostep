# 附录：xv6 实验

本仓库没有内嵌 xv6，不能在这里改内核页表并给出内核实验的输出。对应的用户态实验是第 20 章的两级页表：只映射三个虚拟页，比较线性页表和两级页表的项数。

## 实验步骤

1. 确认仓库里没有 xv6 源码树。
2. 运行用户态对照：

```bash
python3 02-virtualization/ch20-advanced-page-tables/multilevel.py
```

3. 记下线性页表项数、实际占用项数，以及 `0x231f` 的物理地址。

## 实验结果

```text
线性页表项数 256
两级页表实际占用项数 48（页目录 16 项 + 2 张二级表）
VA 0x231f -> PA 0x051f
未映射地址缺页：PDE 0 PTE 0 无效
```

这不是 xv6 内核启动后的 `pgtbl` 打印。
